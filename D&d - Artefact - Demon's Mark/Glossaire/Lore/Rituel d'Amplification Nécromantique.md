# Rituel d'Amplification Nécromantique

*   **Type :** Rituel Magique
*   **Créateur :** **[[Borgoth]]**

## Effet
*   Amplifie le contrôle d'un nécromancien sur les morts-vivants.

## Méthode
*   Le nécromancien doit passer une nuit entière enfermé dans un cercueil avec un mort-vivant.
