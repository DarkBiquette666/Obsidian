# Invocation d'Eidolon

**Niveau** : 2
**École** : Invocation
**Temps d'incantation** : 1 action
**Portée** : 9 mètres
**Composantes** : V, S, M (une pièce d'argent)
**Durée** : [[Concentration]], jusqu'à 1 minute

Vous ouvrez une faille pour invoquer votre eidolon.
*   **Si votre eidolon n'était pas invoqué** : Il apparaît comme d'habitude, mais disparaît à la fin du sort (1 minute). Il ne peut pas toucher de créature protégée contre le Mal/Bien.
*   **Si votre eidolon a été renvoyé à cause de dégâts (0 PV)** : Ce sort permet de le rappeler temporairement avec 1 PV (ou ses PV restants ? Le texte est ambigu, généralement "comme d'habitude" implique ses PV actuels, donc faible).
*   **Si votre eidolon est déjà là** : Le sort n'a aucun effet.

**Au niveau supérieur** (Niveau 3) : La durée passe à 10 minutes.
