# Discrétion

## Description
Un jet de Dextérité (Discrétion) est réalisé lorsque vous essayez de vous cacher des ennemis, de vous faufiler devant des gardes, de vous éclipser sans vous faire remarquer, ou de vous approcher de quelqu'un sans être vu ou entendu.

## Caracteristique
Dextérité
