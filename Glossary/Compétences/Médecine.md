# Médecine

## Description
Un jet de Sagesse (Médecine) vous permet d'essayer de stabiliser un compagnon mourant ou de diagnostiquer une maladie. Vous pouvez également l'utiliser pour déterminer la cause de la mort d'une créature ou identifier un poison.

## Caracteristique
Sagesse
