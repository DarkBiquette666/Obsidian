# Dressage

## Description
Quand il est question de savoir si vous pouvez calmer un animal domestique, empecher une monture de s'effrayer, ou deviner les intentions d'un animal, le MD peut demander un jet de Sagesse (Dressage). Vous effectuez egalement un jet de Sagesse (Dressage) pour controler votre monture lorsque vous tentez une manoeuvre risquee.

## Caracteristique
Sagesse
