# Artificier en herbe

**Prérequis :** —

## Description
Vous apprenez 1 sort mineur et 1 sort de niveau 1 d'artificier (à lancer sans emplacement), maîtrise d'un type d'outils d'artisan.

## Avantages
- Apprenez 1 sort mineur d'artificier
- Apprenez 1 sort de niveau 1 d'artificier (sans emplacement)
- Maîtrise d'un type d'outils d'artisan
