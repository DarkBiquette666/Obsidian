# Combattant à deux armes

**Prérequis :** —

## Description
Vous maîtrisez le combat à deux armes et obtenez les avantages suivants :

- Vous gagnez un bonus de +1 à la CA si vous utilisez une arme de corps à corps distincte dans chaque main.
- Vous pouvez utiliser le combat à deux armes même si les armes de corps à corps à une main que vous tenez ne sont pas légères.
- Vous pouvez déployer une arme à une main alors que normalement vous ne pourraisez faire que pour une seule.

## Avantages
- +1 CA avec une arme dans chaque main
- Utilisez le combat à deux armes sans armes légères
- Pouvez déployer une arme rapidement
