# Empaleur

**Prérequis :** —

## Description
Vous avez atteint une telle précision pour empaler durant au combat, que cela vous confère les avantages suivants :

- Augmentez votre valeur de Force ou de Dextérité de 1, jusqu'à un maximum de 20.
- Une fois par tour, lorsque vous touchez une créature avec une attaque qui inflige des dégâts performants à une créature, vous pouvez utiliser un dé de dégâts supplémentaire pour déterminer les dégâts performants subis sur la cible.

## Avantages
- +1 Force ou Dextérité (max 20)
- 1/tour ajouter un dé de dégâts supplémentaire
