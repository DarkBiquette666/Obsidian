# Résilient

**Prérequis :** —

## Description
Choisissez une caractéristique. Vous gagnez les avantages suivants :

- Augmentez votre valeur de cette caractéristique de 1, jusqu'à un maximum de 20.
- Vous gagnez la maîtrise des jets de sauvegarde qui utilisent la caractéristique choisie.

## Avantages
- +1 à une caractéristique (max 20)
- Maîtrise des jets de sauvegarde
