# Expert

**Prérequis :** —

## Description
Vous avez perfectionnez votre maîtrise avec des compétences particulières, ce qui vous confère les avantages suivants :

- Augmentez la valeur d'une caractéristique de votre choix de 1, jusqu'à un maximum de 20.
- Vous apprenez la maîtrise d'une compétence de votre choix.
- Choisissez une compétence que vous maîtrisez. Vous gagnez l'expertise de cette compétence, ce qui signifie que vous doublisez votre bonus de maîtrise pour tout jet de maîtrise de cette compétence. La compétence que vous choisissez doit être une compétence que vous avez beaucoup étudiée ou dont vous avez beaucoup d'expérience. La compétence que vous choisissez doit être une compétence dont les bénéfices pas déjà d'une capacité qui double votre bonus de maîtrise.

## Avantages
- +1 à une caractéristique (max 20)
- Maîtrise d'une compétence
- Expertise dans une compétence que vous maîtrisez
