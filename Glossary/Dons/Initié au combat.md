# Initié au combat

**Prérequis :** Maîtrise des armes de guerre

## Description
Votre entraînement martial vous a permis de développer un style de combat particulier. En conséquence, vous apprenez une option de Style de combat de votre classe de guerrier. Si vous n'avez pas d'un style, celui que vous choisissez doit être un style que vous n'avez pas. Chaque fois que vous atteignez un niveau accordant la capacité Amélioration de caractéristiques, vous pouvez remplacer le style de combat de ce don par un autre style de combat de votre classe de guerrier que vous n'avez pas.

## Avantages
- Apprenez 1 option de Style de combat
- Pouvez remplacer à chaque amélioration de caractéristiques
