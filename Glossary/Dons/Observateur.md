# Observateur

**Prérequis :** —

## Description
Vous notez rapidement les détails dans votre environnement. Vous gagnez les avantages suivants :

- Augmentez votre valeur d'Intelligence ou de Sagesse de 1, jusqu'à un maximum de 20.
- Si vous voyez la bouche d'une créature alors qu'elle parle une langue que vous comprenez, vous pouvez interpréter ce qu'elle dit en lisant sur les lèvres.
- Vous avez un bonus de +5 à vos jets de Sagesse (Perception) passive.

## Avantages
- +1 Intelligence ou Sagesse (max 20)
- Lecture sur les lèvres
- +5 à Perception passive
