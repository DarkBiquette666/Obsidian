# Soigneur

**Prérequis :** —

## Description
Vous savez où un habit est inefficace, ce qui vous permet de guérir les blessures rapidement pour que vous ailles puissent retourner au combat. Vous gagnez les avantages suivants :

- Lorsque vous utilisez une trousse de soins pour stabiliser une créature mourante, cette créature regagne également 1 point de vie.
- Par une action bonus, vous pouvez essayer de guérir une créature de feu en utilisant d'une trousse de soins pour soigner une créature de feu en utilisant d'une trousse de soins pour se retirer les points de vie temporaires du. La créature ne peut pas bénéficier de nouveaux points de soins de nouveau jusqu'à ce qu'elle termine un repos court ou long.

## Avantages
- Stabilisez les créatures avec soins
- Action bonus pour soigner un peu
