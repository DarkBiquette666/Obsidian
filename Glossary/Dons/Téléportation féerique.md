# Téléportation féerique

**Prérequis :** Elfe (haut)

## Description
En puisant dans votre ascendance féerique, vous pouvez passer momentanément par l'éthérée pour raccourcir votre chemin d'un point à un autre. Vous obtenez les avantages suivants :

- Augmentez votre valeur d'Intelligence ou de Charisme de 1, pour un maximum de 20.
- Vous apprenez le sort foulée brûmeuse et pouvez le lancer une fois sans dépenser d'emplacement de sort. Une fois que vous avez lancé l'un de ces sorts de cette manière, vous ne pouvez plus le lancer de cette manière jusqu'à ce que vous ayez terminé un repos long. L'Intellignce et votre caractéristique d'incantation pour le sort.

## Avantages
- +1 Intelligence ou Charisme (max 20)
- Apprenez et lancez foulée brûmeuse 1/repos long
