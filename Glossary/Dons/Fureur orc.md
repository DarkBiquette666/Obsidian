# Fureur orc

**Prérequis :** Demi-orc

## Description
La furceur orc brille brille sans relâche. Vous obtenez les avantages suivants :

- Augmentez votre valeur de Force ou de Constitution de 1, pour un maximum de 20.
- Lorsque vous touchez au cours d'une attaque effectuée avec une arme courante ou de guerre, vous pouvez lancer un nouveau dé de dégâts de l'Ajouter en tant que dégâts supplémentaires du type de l'arme. Une fois cette capacité utilisée, vous devez terminer un repos court ou long avant de pouvoir l'utiliser.
- Immédiatement après avoir utilisé votre Endurance implacable, vous pouvez utiliser votre réaction pour effectuer une attaque avec une arme.

## Avantages
- +1 Force ou Constitution (max 20)
- Relancez les dégâts d'attaque 1/repos court ou long
- Réaction d'attaque après Endurance implacable
