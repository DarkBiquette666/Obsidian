# Partition de Sommeil

**Type :** Objet Merveilleux (Consommable)
**Rareté :** Peu commun
**Prix :** 150 po
**Poids :** 0 kg

> [!info] Description
> Une feuille de papier à musique dont les notes semblent s'endormir et glisser vers le bas de la page.

**Propriété :** Un barde peut utiliser sa **Réaction** ou une **Action** pour jouer cette mélodie spécifique en combat. En jouant les notes, la partition se consume. Cela lance le sort **Sommeil** (niveau 1) centré sur le barde (affectant les créatures autour de lui, sauf lui-même).
