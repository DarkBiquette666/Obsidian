# Coquillage Messager

**Type :** Objet Merveilleux
**Rareté :** Commun
**Prix :** 25 po
**Lieu :** Padhiver - Le Bazar des Marées

> [!info] Description Boutique
> "Peut enregistrer un message de 10 mots max. Le message se répète quand on souffle dedans."

**Propriété :**
*   **Enregistrement :** Murmurez dans le coquillage en maintenant la pointe.
*   **Lecture :** Soufflez doucement dedans pour entendre le message avec la voix de l'expéditeur.
*   Le message reste jusqu'à ce qu'un nouveau soit enregistré.
