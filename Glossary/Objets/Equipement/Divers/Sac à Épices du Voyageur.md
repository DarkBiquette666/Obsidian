# Sac à Épices du Voyageur

**Type :** Objet Merveilleux
**Rareté :** Commun
**Prix moyen :** 25 po

> [!info] Description
> Une petite bourse qui contient toujours l'épice dont vous avez envie.

**Propriété :**
*   Rend n'importe quel repas insipide délicieux.
*   Si utilisé lors d'un **Repos Court**, vous récupérez **+1 Point de Vie** pour chaque Dé de Vie dépensé.
