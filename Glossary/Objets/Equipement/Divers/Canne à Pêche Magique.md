# Canne à Pêche Magique

**Type :** Objet Merveilleux
**Rareté :** Commun
**Prix moyen :** 50 po

> [!info] Description
> Une canne en bois de fer avec un fil de soie d'araignée inusable.

**Effet :**
*   Confère un **Avantage** aux tests de **Sagesse (Survie)** pour pêcher.
*   Une fois par jour, vous pouvez lancer le mot de commande pour que l'hameçon cherche automatiquement le poisson le plus proche (garantit une prise en 1d4 minutes).
