# Lanterne Sourde (Magique)

**Type :** Objet Merveilleux
**Rareté :** Commun
**Prix moyen :** 50 po

> [!info] Description
> Une lanterne sourde dont le verre change de couleur.

**Propriété :**
Fonctionne comme une lanterne sourde normale.
Action Bonus : Vous pouvez changer la couleur de la lumière (Rouge, Bleu, Vert, Blanc). Utile pour faire des signaux.
