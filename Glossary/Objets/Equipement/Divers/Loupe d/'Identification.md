# Loupe d'Identification

**Type :** Objet Merveilleux
**Rareté :** Peu Commun
**Prix moyen :** 100 po

> [!info] Description
> Une loupe cerclée d'or avec des runes minuscules sur le verre.

**Propriété :**
*   Confère un **Avantage** aux tests d'**Intelligence (Investigation)** pour examiner de petits objets (bijoux, mécanismes, documents).
*   Permet de lire les écritures minuscules sans difficulté.
