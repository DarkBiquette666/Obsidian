# Piton d'Ancrage Indestructible

**Type :** Objet Merveilleux
**Rareté :** Peu Commun
**Prix moyen :** 100 po

> [!info] Description
> Un piton d'escalade gris mat qui semble absorber la lumière.

**Propriété :**
Lorsque vous enfoncez ce piton dans la roche et prononcez le mot de commande "Tenir", il devient inamovible (comme un *Sceptre Inamovible* mais doit être inséré dans une surface).
Il peut supporter jusqu'à 1000 kg.
Mot de commande "Lâcher" pour le retirer.
