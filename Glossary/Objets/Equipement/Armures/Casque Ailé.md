# Casque Ailé

**Type :** Casque (Objet Merveilleux)
**Rareté :** Peu Commun
**Prix moyen :** 200 po

> [!info] Description
> Un casque en acier orné de deux ailes d'oiseau sur les côtés.

**Propriété :**
*   Confère un **Avantage** aux tests de **Charisme (Intimidation)**.
*   Une fois par jour, vous pouvez utiliser une Action Bonus pour faire un saut extraordinaire (sort **Saut** sur soi-même pour 1 minute).
