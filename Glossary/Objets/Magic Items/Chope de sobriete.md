# Chope de sobriete

*Wondrous item, common*

## Description

Cette chope est sculpte d'un visage severe sur un cote. Vous pouvez y boire de la biere, du vin ou toute autre boisson alcoolisee non magique sans vous enivrer. La chope n'aucun effet sur les liquides magiques ou les substances nocives telles que le poison.
