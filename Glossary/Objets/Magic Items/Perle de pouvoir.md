# Perle de pouvoir

*Objet merveilleux, peu commun (nécessite un lien par un lanceur de sorts)*

## Description

Tant que cette perle est sur vous, vous pouvez utiliser une action pour prononcer son mot de commande et récupérer un emplacement de sort dépensé.

## Limitation

Si l'emplacement de sort était de niveau 4 ou supérieur, le nouvel emplacement est de niveau 3.

## Réutilisation

Une fois que vous avez utilisé la perle, elle ne peut être réutilisée avant la prochaine aube.
