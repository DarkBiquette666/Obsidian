# Cor du Valhalla

*Wondrous item, rare (silver or bronze) very rare (bronze) or legendary (iron)*

## Description

Vous pouvez utiliser une action pour souffler dans ce cor. En reponse, des esprits guerriers venant du Valhalla apparaissent dans un rayon de 18 mètres autour de vous. Ils utilisent les statistiques du [berserker](https://www.aidedd.org/dnd/monstres.php?vf=berserker). Ils retournent au Valhalla au bout d'une heure ou lorsqu'ils tombent à 0 points de vie. Une fois que vous avez utilise le cor, il ne peut pas être reutilise avant que 7 jours ne se soient ecoules.

## Types

On connait à ce jour l'existence de quatre types de cor du Valhalla, chacun fin d'un métal different. Le type du cor determine combien de berserkers repondent à sa convocation, de même que les conditions necessaires à son utilisation. Le MD choisit le type du cor ou le determine aleatoirement.

| Type | Berserkers invoques | Condition |
|------|-------------------|-----------|
| Argent | 2d4 + 2 | Aucune |
| Airain | 3d4 + 3 | maîtrise de toutes les armes courantes |
| Bronze | 4d4 + 4 | maîtrise de toutes les armures intermediaires |
| Fer | 5d4 + 5 | maîtrise de toutes les armes de guerre |

## Usage

Si vous soufflez dans le cor sans remplir ses conditions d'utilisation, les berserkers invoques vous attaquent. Si vous remplissez les conditions, ils sont amicaux envers vous et vos compagnons et suivent vos ordres.
