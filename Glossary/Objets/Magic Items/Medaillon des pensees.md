# Médaillon des pensées

*Objet merveilleux, peu commun (nécessite un lien)*

## Description

Le médaillon possède 3 charges. Lorsque vous le portez, vous pouvez utiliser une action et dépenser 1 charge pour lancer le sort *détection des pensées* (sauvegarde DD 13) depuis le médaillon.

## Récupération de charges

Le médaillon récupère 1d3 charges dépensées chaque jour à l'aube.
