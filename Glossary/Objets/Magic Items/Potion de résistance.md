# Potion de résistance

*Potion, peu commun*

Lorsque vous buvez cette potion, vous gagnez une résistance à un type de dégâts pendant 1 heure. Le MD choisit le type ou le détermine au hasard parmi les options ci-dessous.

## Types de dégâts

2. Froid
3. Feu
4. Force
5. Foudre

8. Psychique
