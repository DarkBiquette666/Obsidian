# Perle désaltérante

*Objet merveilleux, commun*

## Description

Cette perle spongieuse, sans saveur et gélatineuse, se dissout dans un liquide, transformant jusqu'à l'équivalent d'une pinte en eau potable fraîche et froide. La perle n'aucun effet sur les liquides magiques ou les substances nocives telles que le poison.
