# Table de Rencontre : Mine

Type : [[Système_Rencontres]]
Biome : Mine / Donjon Souterrain

| d100 | Événement | Détails |
|:---:|---|---|
| **01-10** | **Silence de Mort** | Le silence est total, seulement troublé par la respiration du groupe et le goutte-à-goutte de l'eau. |
| **11-20** | **Éboulement Mineur** | Des gravats tombent du plafond. La structure est instable ici. Avancer avec précaution. |
| **21-30** | **Vieux Matériel** | Un chariot de mine rouillé ou des pics brisés laissés par les mineurs précédents. |
| **31-40** | **Puits de Mine** | Un trou vertical profond au milieu du chemin. On n'en voit pas le fond. |
| **41-50** | **Champignons** | Une zone humide couverte de champignons phosphorescents (source de lumière faible). |
| **51-55** | **Mineur Égaré** | Un nain ou un humain perdu, affamé ou blessé. Il parle d'ombres qui bougent. |
| **56-60** | **Filons** | Une veine de minerai (cuivre, fer, ou rare si chanceux) visible sur la paroi. |
| **61-65** | **Gaz Toxique** | Une odeur d'œuf pourri. Gaz inflammable ou toxique. Attention aux torches ! |
| **66-70** | **Rats Géants** | Une infestation. 2d6 [[Rat géant]]s ou une [[Nuée de rats]] attirés par les rations. |
| **71-75** | **Kobolds** | Un piège se déclenche, suivi de ricanements. 2d4 [[Kobold]]s (et peut-être un [[Kobold ailé]]) harcèlent le groupe. |
| **76-80** | **Araignées** | Des toiles remplissent le tunnel. 1d4 [[Araignée géante]]s ou une [[Araignée de phase]]. |
| **81-85** | **Cube Gélatineux** | Un couloir semble étrangement propre... C'est un [[Cube gélatineux]] qui avance silencieusement. |
| **86-90** | **Grick** | Un [[Grick]] camouflé dans les rochers tombe du plafond sur une proie isolée. |
| **91-95** | **Oxydeur** | Un [[Oxydeur]] (Rust Monster) flaire le métal des armures des aventuriers. Danger pour l'équipement ! |
| **96-99** | **Duergars** | Une patrouille de 1d4 [[Duergar]]s invisibles ou agrandis. Ils n'aiment pas les intrus. |
| **100** | **Xorn** | Un [[Xorn]] traverse la paroi de pierre comme si c'était de l'eau, cherchant des gemmes à manger. |
