# Chasseur

## Description
L'archétype du Chasseur est le choix classique du rodeur : le protecteur de la nature et de la civilisation contre les menaces.

## Capacités

### Niveau 3 : Proie du Chasseur (Hunter's Prey)
Choisissez l'une des options suivantes (modifiable après Repos Long en 2024) :
*   **Tueur de Colosses (Colossus Slayer)** : 1d8 dégâts supplémentaires par tour si la cible est blessée.
*   **Briseur de Horde (Horde Breaker)** : Une attaque supplémentaire contre une créature différente à 1,50 m de la première.

### Niveau 7 : Tactiques Défensives (Defensive Tactics)
Choisissez une option (modifiable) :
*   **Échapper à la Horde** : Les attaques d'opportunité contre vous ont un désavantage.
*   **Défense contre Multiattaque** : +4 CA après la première attaque d'une créature.
*   **Volonté de Fer** : Avantage contre la peur.

### Niveau 11 : Multiattaque (Multiattack)
Choisissez une option :
*   **Volée** : Attaquez toutes les créatures dans un rayon de 3 mètres autour d'un point.
*   **Attaque Tourbillon** : Attaquez toutes les créatures à 1,50 m de vous.

### Niveau 15 : Défense de Chasseur Supérieure (Superior Hunter's Defense)
Choisissez une option :
*   **Esquive** : Réaction pour diviser par deux les dégâts d'une attaque.
*   **Debout face à la marée** : Réaction pour rediriger une attaque manquée vers une autre créature.
