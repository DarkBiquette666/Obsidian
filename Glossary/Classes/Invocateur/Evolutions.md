# Évolutions des Eidolons

Les points de la **Réserve d'évolution** peuvent être dépensés pour acheter ces améliorations. L'invocateur peut les réassigner à chaque niveau.

## Évolutions à 1 Point

*   **Armure naturelle améliorée** : +2 CA. (1 fois tous les 5 niveaux).
*   **Attaque magique** : Les attaques naturelles comptent comme magiques.
*   **Branchies** : Respiration sous l'eau.
*   **Dégâts améliorés** : Augmente le dé de dégâts d'une attaque naturelle d'un cran (ex: 1d6 -> 1d8).
*   **Escalade** : Vitesse d'escalade égale à la vitesse de base.
*   **Griffes** : Paire de griffes (1d4 tranchant). Nécessite Membres (bras).
*   **Magie de base** : Lance un tour de magie (Invocateur) 1/jour (ou 3/jour pour +2 pts).
*   **Membres** : Paire de bras ou jambes supplémentaires.
*   **Monture** : Formé pour être monté (doit être +1 taille que le cavalier).
*   **Morsure** : Attaque de morsure (1d6 perforant). 1.5x For si seule attaque.
*   **Nage** : Vitesse de nage égale à vitesse de base.
*   **Pinces** : Paires de pinces (1d6). Bonus aux tests de lutte (Saisie).
*   **Sabots** : Paire de sabots (1d4). Nécessite Membres (jambes).
*   **Queue** : +Equilibre (Acrobaties).
*   **Coup de Queue** : Attaque de queue (1d6 contondant).
*   **Tentacule** : Attaque de tentacule (1d4 contondant).
*   **Souffle d'Ailes** : Attaque de zone (1d4 contondant). Nécessite Vol.
*   **Allonge** : +1.5m de portée pour une attaque.
*   **Bondissement** : Attaque en action bonus après l'action Foncer (Flèche ?).
*   **Compétent** : Expertise dans une compétence (Double maîtrise).
*   **Coup** : Attaque dévastatrice (1d8). Remplace Griffes.
*   **Dard** : Attaque de queue (1d4 perforant).
*   **Flairement Aigu** : Odorat 18m (9m contre le vent). Détection, pas localisation précise.
*   **Glissant** : Avantage pour échapper à la lutte.
*   **Collant** : Avantage pour maintenir la lutte.

## Évolutions à 2 Points

*   **Augmentation de caractéristiques** : +2 à une carac. (1 fois tous les 6 niveaux).
*   **Attaques élémentaires** : +1d6 dégâts (Feu, Froid, Acide ou Foudre) sur toutes les attaques. (Niv 5+).
*   **Constriction** : Dégâts auto en cas de lutte réussie. (Serpentin uniquement).
*   **Vol** : Ailes (Vitesse = Vitesse base). +1 pt pour vol magique (surnaturel). (Niv 5+).
*   **Sang** : Cornes (1d6 dégâts).
*   **Saisie** : Lutte en action libre après une attaque réussie. (Taille cible <= Eidolon).
*   **Flairement Aigu (Supérieur)** : Détection odeur 1.6km (sang dans l'eau).
*   **Magie mineure** : Sort niveau 1 inné (1/jour). Niv 4+.
*   **Poison** : Venin sur morsure/piqûre (1d4/round pendant 4 rounds, JdS Con).
*   **Râteau** : Dégâts extra (1d4) en lutte. (Quadrupède, Niv 4+).
*   **Déchirure** : Dégâts extra si 2 griffes touchent la même cible. (Niv 6+).
*   **Effacement d'Ombre** : Avantage Discrétion (pénombre). Invisibilité 1 action (obscurité).
*   **Forme d'Ombre** : Concealment (Désavantage attaques contre lui). Dégâts /2 contre corporels.
*   **Sens des Vibrations** : Perception des tremblements 9m. (Niv 7+).
*   **Entraînement aux Armes** : Maîtrise armes simples (ou martiales pour +2 pts).

## Évolutions à 4 Points

*   **Vision aveugle** : 9m. (Niv 11+).
*   **Souffle** : Cône 9m ou Ligne 18m. 1d6/niveau dégâts élémentaires. 1/jour (ou + pour +1 pt). (Niv 9+).
*   **Régénération** : 1 PV/round (si > 0 PV). (Niv 11+).
*   **Forme Incorporelle** : Incorporel 1 round/niveau par jour. (Niv 15+).
*   **Grand** : Taille devient Grande. +2 For, +2 Con, +2 CA naturelle, -2 Dex. Allonge +1.5m. (Niv 8+).
    *   **Immense** (6 pts) : +4 For, +4 Con, +4 CA, -4 Dex. (Niv 13+ ?).
*   **Sans Respiration** : Immunité gaz/poison inhalé. (Niv 11+).
*   **Magie Ultime** : Sort majeur inné (1/jour). Niv 11+.
*   **Voir dans les Ténèbres** : Vision ténèbres magiques 36m. (Niv 9+).
*   **Engloutir** : Avaler créature agrippée (taille inférieure). Dégâts auto + Aveuglé/Entravé. (Niv 9+).
*   **Toile** : Tisser toile, grimper sur toile, sens de la toile. (Niv 7+).
*   **Présence Effroyable** : Aura de peur 9m (Action ou sur attaque). (Niv ?).
*   **Immunité** : Immunité à un élément (Feu, Froid, etc.). (Niv 7+).
*   **Terrier** : Vitesse fouissage = 1/2 vitesse. (Niv 9+).
