# Guerrier de l'Ombre

## Description
Les moines de la Voie de l'Ombre suivent une tradition qui valorise la furtivité et le subterfuge. Ils sont parfois appelés ninjas ou danseurs de l'ombre, et servent d'espions et d'assassins.

## Capacités

### Niveau 3 : Arts de l'Ombre (Shadow Arts)
Vous pouvez dépenser des Points de Focalisation (Focus Points) pour lancer certains sorts :
*   *Ténèbres* (Darkness) : 1 Point (ou 2, coût réduit 2024). Vous pouvez voir dans vos propres ténèbres magiques.
*   *Silence* (Silence) : 1 Point.
*   *Passage sans trace* (Pass Without Trace) : 1 Point.
*   *Illusion mineure* (Minor Illusion) : Cantrip gratuit.

### Niveau 6 : Pas de l'Ombre (Shadow Step)
Lorsque vous êtes dans une lumière faible ou dans les ténèbres, vous pouvez vous téléporter en Action Bonus jusqu'à 18 mètres (60 feet) vers un espace inoccupé que vous pouvez voir qui est aussi dans une lumière faible ou les ténèbres.
Après la téléportation, vous avez l'Avantage sur la prochaine attaque au corps à corps que vous faites avant la fin du tour.

### Niveau 11 : Cape d'Ombres (Cloak of Shadows)
Lorsque vous êtes dans une lumière faible ou dans les ténèbres, vous pouvez utiliser votre Action (ou Action Bonus en 2024) pour devenir Invisible.
L'invisibilité dure jusqu'à ce que vous attaquiez, lanciez un sort ou entriez dans une zone de lumière vive.

### Niveau 17 : Opportuniste (Opportunist)
Lorsqu'une créature à 1,50 m (5 feet) de vous est touchée par une attaque faite par une créature autre que vous, vous pouvez utiliser votre Réaction pour faire une attaque au corps à corps contre cette créature.
