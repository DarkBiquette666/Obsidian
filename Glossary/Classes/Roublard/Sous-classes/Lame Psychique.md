# Lame Psychique

## Description
Les Lames Psychiques frappent avec l'esprit, coupant à travers les barrières physiques et mentales.

## Capacités

### Niveau 3 : Pouvoir Psionique (Psionic Power)
Réserve de dés psioniques (d6, augmente avec le niveau).
Utilisations :
*   **Talent Psi** : Ajouter le dé à un test de compétence raté.
*   **Chuchotement Psi** : Télépathie de groupe.

### Niveau 3 : Lames Psychiques (Psychic Blades)
Vous pouvez matérialiser des lames d'énergie psychique.
Action Attaquer : Lame dans une main (1d6 + Dex dégâts psychiques).
Action Bonus : Seconde lame (1d4 + Dex dégâts psychiques).
Les lames disparaissent après l'attaque. Ne laissent pas de marque.
**Mise à jour 2024** : Propriété **Vex** (Avantage sur prochaine attaque) sur les lames. Portée étendue (lancé 18m/60ft). Utilisable sur Attaque d'Opportunité.

### Niveau 9 : Lames d'Âme (Soul Blades)
*   **Frappe guidée (Homing Strikes)** : Si vous ratez une attaque avec vos lames, lancez un dé psionique et ajoutez-le au jet. Dé dépensé seulement si ça touche.
*   **Téléportation Psychique** : Lancer une lame pour se téléporter à l'endroit où elle atterrit.

### Niveau 13 : Voile Psychique (Psychic Veil)
Vous pouvez devenir Invisible pendant 1 heure (ou jusqu'à attaque).
Une fois gratuit par Repos Long, puis coûte un dé psionique.

### Niveau 17 : Déchirure Mentale (Rend Mind)
Lorsque vous faites une Attaque Sournoise avec vos lames, vous pouvez forcer la cible à faire un jet de sauvegarde de Sagesse. En cas d'échec, elle est Étourdie pendant 1 minute (save fin de tour).
Coût : 3 dés psioniques (ou 1 fois gratuit).
