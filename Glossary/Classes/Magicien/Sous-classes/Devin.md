# Devin

## Description
Le conseil d'un devin est recherché par la royauté comme par les gens du peuple, car tous veulent connaître le passé, le présent et l'avenir.

## Capacités

### Niveau 3 : Savant en Divination (Divination Savant)
Coût réduit pour copier les sorts de divination. Ajout gratuit de sorts de divination au grimoire.

### Niveau 3 : Présage (Portent)
Après chaque Repos Long, vous lancez deux d20 et notez les résultats.
Vous pouvez utiliser ces résultats pour remplacer n'importe quel jet d'attaque, de sauvegarde ou de caractéristique fait par vous ou une créature que vous voyez. Vous devez choisir de le faire avant le jet.

### Niveau 6 : Divination Experte (Expert Divination)
Lorsque vous lancez un sort de divination de niveau 2 ou plus en utilisant un emplacement de sort, vous récupérez un emplacement de sort dépensé. L'emplacement récupéré doit être d'un niveau inférieur au sort lancé et ne peut pas dépasser le niveau 5.

### Niveau 10 : Le Troisième Œil (The Third Eye)
Vous pouvez utiliser votre Action pour gagner un bénéfice jusqu'à votre prochain Repos Long (ou Court selon 2024) :
*   Vision dans le noir (36m/120ft).
*   Vision éthérée.
*   Lecture de toutes les langues.
*   Voir l'invisible.
**Nouveauté 2024** : Permet de lancer *Voir l'invisibilité* sans emplacement de sort.

### Niveau 14 : Présage Supérieur (Greater Portent)
Vous lancez trois d20 pour votre capacité Présage au lieu de deux.
