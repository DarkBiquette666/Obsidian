# Vigueur fiélonne

prerequis:: [[Occultiste]] 2



**Prérequis : Occultiste de niveau 2+**

Vous pouvez lancer *[simulacre de vie](https://www.aidedd.org/spell/fr/simulacre-de-vie)* sur vous-même sans dépenser un emplacement de sort. Lorsque vous lancez le sort avec cette capacité, vous ne lancez pas le dé pour les points de vie temporaires ; vous obtenez automatiquement le nombre le plus élevé du dé.
