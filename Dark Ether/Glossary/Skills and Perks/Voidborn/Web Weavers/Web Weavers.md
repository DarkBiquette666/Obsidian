# Web Weavers

## Description
Summons 2 immobile spiders that shoot webs to Root enemies.

## Statistics

| Property | Value | Notes |
|-----------|--------|-------|
| **Type** | Summon | Utility Minion |
| **Count** | 2 | Immobile |
| **Effect** | Root | Crowd Control |

## Perks System

### Available Perks

1. **[[Toxic Web]]** - Webs apply Poison.
2. **[[Silken Cocoon]]** - Can target ally to grant a Shield.
3. **[[Sticky Trap]]** - Creates a Slow zone on the ground.
4. **[[Vibrations]]** - Detects and reveals invisible enemies.
5. **[[Spider Feast]]** - Bonus damage against Rooted targets.
