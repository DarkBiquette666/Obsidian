# Call of the Colony

## Description
Summons 5 weak Larvae that rush the nearest enemy. Temporary swarm.

## Statistics

| Property | Value | Notes |
|-----------|--------|-------|
| **Type** | Summon | Mass Swarm |
| **Count** | 5 | Weak minions |
| **Duration** | Short | |

## Perks System

### Available Perks

1. **[[Kamikazes]]** - Larvae explode on contact.
2. **[[Fodder]]** - Larvae can be eaten by other minions to heal them.
3. **[[Continuous Stream]]** - Spawns 1 larva per second for 10s.
4. **[[Vampiric Larvae]]** - Larvae attacks heal the player.
5. **[[Flying Mutation]]** - Summons Flies (High Dodge/Flying) instead of Larvae.
