# Parasitic Resonance

## Description
When the linked enemy has both bleeding and poison status effects, the life drain rate increases by 100% and the link automatically spreads to other enemies suffering from both DoTs. This creates cascading parasitic networks requiring sophisticated multi-DoT builds.

## Mechanics

### Activation Requirements
- **Primary Condition:** Target has bleeding status
- **Secondary Condition:** Target has poison status
- **Both Required:** Must have both simultaneously
- **Detection:** Continuous status checking
- **Instant Trigger:** Immediate on condition met

### Effect Amplification
- **Drain Bonus:** +100% life drain rate
- **Multiplicative:** Stacks with other bonuses
- **Per Target:** Each resonating enemy calculated
- **Dynamic Updates:** Adjusts as statuses change

### Auto-Spread System
- **Trigger:** Any dual-DoT enemy in range
- **Automatic:** No additional input needed
- **Chain Reaction:** Can cascade through groups
- **Range Limited:** Standard link distance applies
- **Network Creation:** Forms parasitic webs
