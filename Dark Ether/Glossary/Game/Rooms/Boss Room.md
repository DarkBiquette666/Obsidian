# Boss Room

The climactic encounter at the end of each floor. Defeat the Floor Boss to progress.

---

## Flow

1. Clear all rooms on the floor (or reach the boss room)
2. Enter the Boss Room
3. Defeat the Floor Boss
4. Receive rewards
5. Proceed to next floor (or end run if final boss)

---

## Rewards

| Reward Type | Description |
|-------------|-------------|
| **Equipment** | Weapons, armor, accessories |
| **Resources** | High-value materials for crafting |
| **Meta-progression items** | Perk unlocks, Stat-up points |
| **Story elements** | Lore, narrative progression |

---

## Boss Types

### Minor Bosses
- Appear on early/mid floors
- Introduce mechanics gradually
- Examples: [[Xarenthor, The Shadow Weaver]], [[Kyrektor, The Stormcaller]]

### Major Bosses
- Appear on later floors
- Complex mechanics, multiple phases
- Examples: [[Syl'Korath, the Infamous]], [[Aeryn'Tor]], [[Nythra'Zal]]

### Final Boss
- [[The Supreme Void]]
- See [[Gameplay Loop]] for the plot twist

---

## Design Notes

- Boss Rooms are the skill check of each floor
- Defeat sends the player back to the Lobby
- Rewards should feel significant—this is where major progression happens
- Boss difficulty should scale with floor depth
