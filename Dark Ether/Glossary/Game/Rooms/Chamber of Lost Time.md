# Chamber of Lost Time

A rare and mysterious room that exists outside the normal flow of the timeline. Each Chamber offers a **unique, random mechanic** that cannot be found elsewhere.

## Narrative Context

The Chamber of Lost Time is a pocket of reality untouched by the timeline's anomalies—a fragment of a timeline that never was, or perhaps one that has yet to be. Vorathros stumbles upon these chambers by chance, or by proving his worth through swift action.

## Possible Variants

### Treasure Variants

| Variant | Description |
|---------|-------------|
| **Unique Chest** | A single chest guaranteeing a Unique item |
| **Treasure Trove** | Room full of chests with varied loot |

### Blessing Variants

| Variant | Description |
|---------|-------------|
| **Triple Blessing** | Choice of 3 Blessings (any tier available) |

### Merchant Variants

| Variant | Description |
|---------|-------------|
| **Temporal Merchant** | Special merchant with rare Mutations unavailable elsewhere |

### Progression Variants

| Variant | Description |
|---------|-------------|
| **Perk Unlock** | Unlock a new Perk during the run (meta-progression) |
| **Crafting Station** | One-shot crafting opportunity with special options |

### Narrative Variants

| Variant | Description |
|---------|-------------|
| **Echo of the Past** | Narrative event with meaningful choice and consequences |
| **Memory Fragment** | Lore reveal + minor permanent bonus |

### Recovery Variants

| Variant                   | Description                                         |
| ------------------------- | --------------------------------------------------- |
| **Fountain of Lost Time** | Allowed the player to die x time in the current run |

---

## Design Notes

- Each variant should feel **special and memorable**
- The Chamber should never feel like a "bad" room—every variant offers value
- Some variants may be weighted differently based on player state (low HP → higher chance of Fountain?)
- The Chamber does **not** affect Purity/Corruption balance
