# Multiple Projectiles Support
![[Assets/Multiple_Projectiles_Rune.svg|128]]

## Description
A Support Rune that adds additional projectiles to the supported skill. This rune multiplies the number of projectiles created but increases resource costs and reduces individual projectile damage to balance the increased coverage and shotgun potential.

## Mechanics

### Progression
Each level increases the number of projectiles or efficiency. Level 5 unlocks an **Alternate Behavior**.

| Level | Effect | Trade-off |
| :--- | :--- | :--- |
| **Level 1** | **+2** Projectiles | **-35%** Less Projectile Damage<br>**+50%** Resource Cost |
| **Level 2** | **+2** Projectiles | **-30%** Less Projectile Damage<br>**+45%** Resource Cost |
| **Level 3** | **+3** Projectiles | **-30%** Less Projectile Damage<br>**+50%** Resource Cost |
| **Level 4** | **+4** Projectiles | **-25%** Less Projectile Damage<br>**+60%** Resource Cost |
| **Level 5 (Alt)** | **Barrage Mode:** Projectiles are fired sequentially in a stream rather than a spread. **+4** Projectiles. | **No Spread** (Narrow cone).<br>**-20%** Less Damage.<br>Allows all projectiles to easily hit a single target. |

## Compatible Skills
- **Blood Blade:** Adds additional orbiting blades.
- **Void Spitters:** Increases the number of projectiles fired.
- **Ether Ball:** Fires multiple balls in a spread or sequence.
- **Any Projectile Skill:** Generally applicable to skills tagged with `[Projectile]`.

## Strategic Value

- **Area Coverage:** Significantly improves the ability to hit multiple enemies (Levels 1-4).
- **Shotgunning:** The **Level 5 Barrage** variant is a boss-killing specialist, sacrificing area coverage for concentrated single-target DPS.
- **Status Application:** More hits mean more chances to apply status effects (Bleed, Poison, etc.).
