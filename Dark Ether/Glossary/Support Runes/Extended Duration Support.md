# Extended Duration Support
![[Assets/Extended_Duration_Rune.svg|128]]

## Description
Increases the duration of buffs, debuffs, and persisting effects (like puddles or summons).

## Mechanics

### Progression
Level 5 unlocks an **Alternate Behavior**.

| Level | Effect | Trade-off |
| :--- | :--- | :--- |
| **Level 1** | **+30%** Skill Duration | N/A |
| **Level 2** | **+45%** Skill Duration | N/A |
| **Level 3** | **+60%** Skill Duration | N/A |
| **Level 4** | **+75%** Skill Duration | N/A |
| **Level 5 (Alt)** | **Eternal:** Skill lasts until toggled off or zone change. (Only for buffs/minions, not DoTs). | **Reserved Resource:** Instead of a Mana cost, the skill now **Reserves** 15% of Max Mana/Health to maintain. |

## Strategic Value
- **QoL:** Reduces the need to recast buffs like [[Blood Barrier]].
- **DoT Scaling:** Significantly increases total damage per cast for long-lasting poisons or bleeds.
