# Massive Area Support
![[Assets/Massive_Area_Rune.svg|128]]

## Description
Magically expands the blast radius, aura size, or effect range of skills.

## Mechanics

### Progression
Each level increases the Area of Effect. Level 5 unlocks an **Alternate Behavior**.

| Level             | Effect                                 | Trade-off                                                                                                         |
| :---------------- | :------------------------------------- | :---------------------------------------------------------------------------------------------------------------- |
| **Level 1**       | **+20%** Area of Effect                | **+10%** Resource Cost                                                                                            |
| **Level 2**       | **+30%** Area of Effect                | **+15%** Resource Cost                                                                                            |
| **Level 3**       | **+40%** Area of Effect                | **+20%** Resource Cost                                                                                            |
| **Level 4**       | **+50%** Area of Effect                | **+25%** Resource Cost                                                                                            |
| **Level 5 (Alt)** | **Tsunami:** **+100%** Area of Effect. | **+30%** Resource Cost<br>**-30%** Less Damage.<br>Effect expands slowly over 1 second rather than being instant. |
|                   |                                        |                                                                                                                   |

## Strategic Value
- **Screen Clear:** Essential for farming and clearing weaker mobs efficiently.
- **Aura Support:** Makes support auras like [[Life Leech Aura]] cover the entire party/arena easily.
