# Rapid Recharge Support
![[Assets/Rapid_Recharge_Rune.svg|128]]

## Description
Uses chronomancy to accelerate the cooldown recovery of the skill.

## Mechanics

### Progression
Level 5 unlocks an **Alternate Behavior**.

| Level             | Effect                                    | Trade-off                                                                                                                                                         |
| :---------------- | :---------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Level 1**       | **+15%** Cooldown Recovery Rate           | **+10%** Resource Cost                                                                                                                                            |
| **Level 2**       | **+25%** Cooldown Recovery Rate           | **+15%** Resource Cost                                                                                                                                            |
| **Level 3**       | **+35%** Cooldown Recovery Rate           | **+20%** Resource Cost                                                                                                                                            |
| **Level 4**       | **+45%** Cooldown Recovery Rate           | **+25%** Resource Cost                                                                                                                                            |
| **Level 5 (Alt)** | **Overclock:** Skill has **No Cooldown**. | **Stacking Cost:** Each cast increases Mana Cost by **100%** (stacks reset after 4 seconds of not casting the supported skill).<br>**-30%** Damage/Effectiveness. |

## Strategic Value
- **Uptime:** Essential for skills with long cooldowns like Ultimates.
- **Overclock (Lvl 5):** Allows "spamming" a cooldown skill for a short burst window before the mana cost becomes impossible.
