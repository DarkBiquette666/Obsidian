# Skill Tags

Tags are keywords assigned to skills that define their properties and determine compatibility with [[Support Runes]].

---

## How Tags Work

1. Each skill has a set of tags describing its behavior
2. [[Support Runes]] require specific tags to be equipped
3. Stats and modifiers can target skills by tag (e.g., "+20% Projectile Damage")

---

## Tag Categories

### Damage Type
| Tag | Description |
|-----|-------------|
| [[Physical]] | Deals physical damage |
| [[Fire]] | Deals fire damage |
| [[Cold]] | Deals cold damage |
| [[Lightning]] | Deals lightning damage |
| [[Poison]] | Deals poison damage |
| [[Ether]] | Deals ether damage |
| [[Elemental]] | Fire, Cold, or Lightning |

### Damage Source
| Tag | Description |
|-----|-------------|
| [[Attack]] | Weapon-based damage, scales with weapon stats |
| [[Spell]] | Magic-based damage, scales with spell stats |
| [[Over Time]] | Damage applied over duration (DoT) |

### Delivery Method
| Tag | Description |
|-----|-------------|
| [[Projectile]] | Fires objects that travel toward targets |
| [[Melee]] | Close-range combat |
| [[AoE]] | Area of Effect, hits multiple targets in an area |
| [[Chaining]] | Jumps between multiple targets |

### Skill Mechanics
| Tag | Description |
|-----|-------------|
| [[Minion]] | Summons or affects allied creatures |
| [[Aura]] | Persistent area effect around caster or target |
| [[Curse]] | Debuff applied to enemies |
| [[Buff]] | Beneficial effect on self or allies |
| [[Duration]] | Effect persists over time |
| [[Channeling]] | Requires continuous casting |
| [[Movement]] | Involves character movement |
| [[Trigger]] | Activates automatically under conditions |

### Weapon Requirements
| Tag | Description |
|-----|-------------|
| [[Bow]] | Requires bow weapon |
| [[One-Handed]] | Requires one-handed weapon |
| [[Two-Handed]] | Requires two-handed weapon |

### Class-Specific
| Tag | Description |
|-----|-------------|
| [[Blood]] | Blood magic skills (Torin) |

---

## Example: Blood Blade

**Blood Blade** has the following tags:
- `Attack` - Weapon-based skill
- `Blood` - Blood magic
- `Bleed` - Inflicts bleed
- `Persistent` - Remains active
- `Weapon` - Requires weapon

This means:
- Support Runes requiring `Attack` tag can be equipped
- Support Runes requiring `Bleed` tag can be equipped
- Support Runes requiring `Projectile` tag **cannot** be equipped
