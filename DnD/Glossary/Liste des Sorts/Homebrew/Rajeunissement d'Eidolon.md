# Rajeunissement d'Eidolon

**Niveau** : 1
**École** : Évocation
**Temps d'incantation** : 1 action
**Portée** : Touché
**Composantes** : V, S, M (une goutte de votre sang)
**Durée** : Instantanée

Vous posez votre main sur votre eidolon pour refermer ses blessures. Il récupère **1d10 + votre modificateur de caractéristique d'incantation** points de vie.

**À plus haut niveau**. Les soins augmentent de **1d10** pour chaque niveau d'emplacement au-dessus du niveau 1.
