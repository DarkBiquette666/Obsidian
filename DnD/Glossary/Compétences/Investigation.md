# Investigation

## Description
Lorsque vous cherchez des indices et que vous faites des deductions à partir de ces indices, vous effectuez un jet d'Intelligence (Investigation). Vous pouvez deduire l'emplacement d'un objet cache, discerner à partir de l'apparence d'une blessure le type d'arme qui l'a causee, ou determiner le point le plus faible d'un tunnel qui pourrait le faire s'effondrer. Compulser d'anciens parchemins a la recherche d'un fragment de connaissance cache peut aussi necessiter un jet d'Intelligence (Investigation).
