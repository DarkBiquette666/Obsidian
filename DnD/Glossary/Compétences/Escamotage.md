# Escamotage

## Description
Chaque fois que vous tentez un tour de passe-passe ou une manipulation manuelle, comme faire glisser quelque chose dans la poche d'un autre personnage ou cacher un objet sur votre personne, faites un jet de Dexterite (Escamotage). Le MD peut egalement demander un jet de Dexterite (Escamotage) pour determiner si vous pouvez derober une bourse a une autre personne ou lui faire les poches.

## Caracteristique
Dexterite
