# Table de Rencontre : Montagne

Type : [[Système_Rencontres]]
Biome : Montagne

| d100 | Événement | Détails |
|:---:|---|---|
| **01-10** | **Vue Panoramique** | Le ciel est dégagé. Une vue imprenable sur la vallée en contrebas offre un moment de répit. |
| **11-20** | **Vent Glacial** | La température chute brutalement. Les personnages sans vêtements chauds doivent faire un jet de Vigueur (DD 10) ou gagner un niveau de Fatigue. |
| **21-30** | **Chute de Pierres** | Des petits cailloux dévalent la pente, suivis d'un rocher. Jet de *Dextérité* (DD 12) pour éviter 2d6 dégâts contondants. |
| **31-40** | **Écho** | Les bruits du groupe se répercutent étrangement, donnant l'impression d'être suivis. |
| **41-50** | **Nid Vide** | Un nid immense (Roc ou Aigle Géant) mais vide pour le moment. Quelques os traînent. |
| **51-55** | **Ermite** | Un vieux nain ou humain vivant dans une grotte. Il connait les raccourcis locaux. |
| **56-60** | **Pont Suspendu** | Un vieux pont de corde au-dessus d'un ravin. Il semble fragile. Craquera-t-il ? |
| **61-65** | **Chèvres de Montagne** | Un troupeau de [[Chèvre]]s bloque le passage étroit. Elles sont têtues mais inoffensives sauf si provoquées. |
| **66-70** | **Mine Abandonnée** | L'entrée d'une ancienne mine. Lancez 1d6 : sur **4-6**, c'est un vaste complexe ([[Donjon_Mine]]). Sinon, juste une grotte instable. |
| **71-75** | **Aigle Géant** | Un [[Aigle géant]] observe le groupe depuis un pic. Il n'attaque que si on s'approche de son aire. |
| **76-80** | **Harpies** | 1d4 [[Harpie]]s utilisent leur chant pour attirer les voyageurs vers une falaise. |
| **81-85** | **Campement Orc** | Un petit groupe de guerre. Voir [[Orc, chef de guerre]] ou guerriers standards. Ils cuisinent quelque chose de douteux. |
| **86-90** | **GRIFFON !** | Un [[Griffon]] plonge pour attaquer un cheval ou une bête de somme du groupe. |
| **91-95** | **Géant** | Un [[Géant des pierres]] est assis, immobile, ressemblant à un rocher jusqu'à ce qu'il bouge. |
| **96-99** | **Wiverne** | Une [[Wiverne]] affamée en chasse. |
| **100** | **Roc** | L'ombre immense d'un [[Roc]] passe au-dessus. Espérons qu'il ne regarde pas en bas. |
