# Système de Rencontres Aléatoires

## Quand lancer ?
Lancer un **d100** (ou 2d10) dans les situations suivantes :
- **Voyage :** Une fois toutes les 4 heures de voyage ou une fois par "journée" de voyage selon le rythme souhaité.
- **Camping :** Une fois par Long Repos (si la zone est dangereuse).
- **Exploration :** En entrant dans une nouvelle zone majeure d'un biome.

## Lecture du d100
Le résultat détermine la nature de l'événement. Les tables sont calibrées pour que le combat ne soit pas systématique.

| d100 | Type de Rencontre | Description |
|:---:|---|---|
| **01-50** | **Ambiance / Rien** | Le voyage se passe sans encombre. Description sensorielle, météo, petite faune inoffensive. Sert à immerger les joueurs. |
| **51-75** | **Non-Combat / Social** | Un obstacle, un marchand, un voyageur, une ruine mystérieuse ou un défi de compétence. Peut devenir un combat si les joueurs sont agressifs. |
| **76-100** | **Combat** | Une menace potentielle. Peut parfois être évitée ou négociée, mais l'initiative est probable. |

## Modificateurs (Optionnel)
- **Zone Dangereuse :** Ajouter +20 au résultat (augmente les chances de combat).
- **Zone Sécurisée :** Soustraire -20 au résultat.
