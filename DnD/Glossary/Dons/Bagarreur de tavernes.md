# Bagarreur de tavernes

**Prérequis :** —

## Description
Habitué à vous battre comme un chiffonnier en utilisant tout ce qui vous tombe sous la main, vous obtenez les avantages suivants :

- Augmentez votre valeur de Force ou de Constitution de 1, jusqu'à un maximum de 20.
- Vous maîtrisez les armes improvisées.
- Votre attaque à mains nues utilise un d4 pour les dégâts.
- Pendant votre tour, si vous touchez une créature avec une arme improvisée, vous pouvez utiliser une action bonus pour essayer d'engager une lutte avec la cible.

## Avantages
- +1 Force ou Constitution (max 20)
- Maîtrise des armes improvisées
- Attaque à mains nues: d4
- Action bonus pour engager après une attaque avec arme improvisée
