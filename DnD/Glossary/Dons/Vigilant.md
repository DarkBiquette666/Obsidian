# Vigilant

**Prérequis :** —

## Description
Toujours sur le qui-vive pour guetter le danger, vous gagnez les avantages suivants :

- Vous gagnez un bonus de +5 à l'initiative.
- Vous ne pouvez pas être surpris tant que vous êtes conscient.
- Les autres créatures ont n'ont un avantage aux jets d'attaque contre vous du fait que vous les voyez pas.

## Avantages
- +5 à l'initiative
- Pas de surprise si conscient
- Les autres ne bénéficient d'avantage si cachés
