# Linguiste

**Prérequis :** —

## Description
Vous avez étudié les langues et les codes, et bénéficiez des avantages suivants :

- Augmentez votre valeur d'Intelligence de 1, jusqu'à un maximum de 20.
- Vous apprenez trois langues de votre choix.
- Vous pouvez coder des messages avec compétence. D'autres personnes ne peuvent déchiffrer un code qui vous avez enseigné, quelles réussissent un jet d'Intelligence (DD égal à votre valeur d'Intelligence + votre bonus de maîtrise) ou qu'elles utilisent la magie pour le déchiffrer.

## Avantages
- +1 Intelligence (max 20)
- Apprenez 3 langues
- Encodage sécurisé de messages
