# Adepte Martial

**Prérequis :** —

## Description
Vous avez une formation martiale qui vous permet d'effectuer des manœuvres de combat spectaculaires. Vous obtenez les avantages suivants :

- Vous apprenez deux manœuvres de votre choix parmi celles disponibles pour l'archétype de guerrier du maître de bataille. Si un effet vous permet un jet de sauvegarde pour résister aux effets de la manœuvre, le DD du jet de sauvegarde est égal à 8 + votre bonus de maîtrise + votre modificateur de Force ou de Dextérité (selon votre choix).

- Vous gagnez un dé de supériorité (d6). Vous pouvez utiliser ce dé pour alimenter vos manœuvres. Un dé de supériorité dépensé lorsque vous l'utilisez. Vous regagnez ce dé si vous terminez un repos court ou long.

## Avantages
- Apprenez 2 manœuvres de guerrier
- Gagnez 1 dé de supériorité (d6)
