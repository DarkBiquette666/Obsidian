# Lutteur

**Prérequis :** +3 ou plus en Force

## Description
Vous avez développé les compétences nécessaires pour vous défendre tout seul dans les combats de rue. Vous obtenez les avantages suivants :

- Vous avez un avantage aux jets d'attaque contre une créature avec laquelle vous êtes engagé dans un combat.
- Vous pouvez utiliser la saisie pour tenter de bloquer une créature avec qui vous avez engagé dans un combat. Si vous réussissez, la créature est tous entravés jusqu'à la fin de votre tour ou jusqu'à ce que vous finissez une attaque au corps à corps. Si vous tombez à terre, le créature dont vous avez capturé la main qui vous a capturé peut utiliser une réaction pour se sauver.

## Avantages
- Avantage aux attaques dans une prise
- Pouvez bloquer une créature
