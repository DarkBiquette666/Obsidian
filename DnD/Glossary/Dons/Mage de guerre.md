# Mage de guerre

**Prérequis :** Capacité de lancer au moins un sort

## Description
Vous avez pratiqué le lancer de sorts au milieu d'un combat, apprenant des techniques qui vous confèrent les avantages suivants :

- Vous avez un avantage aux jets de sauvegarde de Constitution pour maintenir votre concentration lors un combat lorsque vous subissez des dégâts.
- Vous pouvez effectuer une composante somatique des sorts même si vous avez des armes ou un bouclier dans les mains. Vous pouvez également utiliser un ensemble du sort (comme pour les sorts qui est simplement une composante somatique) même si vous avez les mains pleines.

## Avantages
- Avantage aux sauvegardes de concentration
- Lancez des sorts mains pleines
