# Chanceux

**Prérequis :** —

## Description
Vous avez une chance inexpicable qui semble tomber juste au bon moment. Vous avez 3 points de chance. Chaque fois que vous faites un jet d'attaque, de caractéristique ou de sauvegarde, vous pouvez dépenser un de vos points de chance après avoir lancé le dé mais avant que son effet soit déterminé. Vous redéfinissez le dé d'attaque, de caractéristique ou de sauvegarde. Vous pouvez utiliser cette capacité quand un autre créature dépense un point de chance pour influencer le résultat d'un jet que vous effectuez. Vous engagez vos points de chance dépensés lorsque vous terminez un repos long.

## Avantages
- 3 points de chance par repos long
- Dépenser un point pour relancer un dé
- Pouvez l'utiliser après avoir lancé le dé
