# Lanterne Sourde (Magique)

**Type :** Objet Merveilleux
**Rareté :** Commun
**Prix :** 50 po
**Lieu :** Lunargent - Brocante de l'Ancien

> [!info] Description Boutique
> "Change de couleur selon l'humeur du porteur."

**Propriété :**
Éclaire comme une lanterne sourde normale.
*   **Effet :** La flamme change de couleur involontairement.
    *   Rouge : Colère / Combat
    *   Bleu : Calme / Tristesse
    *   Jaune : Joie / Excitation
    *   Violet : Peur
*   Donne un **Désavantage** aux tests de **Charisme (Tromperie)** si la lumière est visible.
