# Cadenas sournois

*Wondrous item, common*

## Description

Cette serrure semble être une serrure ordinaire et vient avec une seule cle. Ses gobelets s'ajustent magiquement pour frustrer les cambrioleurs. Les jets de Dextérité effectues pour crocheter la serrure ont un desavantage.
