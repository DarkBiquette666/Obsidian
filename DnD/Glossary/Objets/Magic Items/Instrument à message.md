# Instrument à message

*Objet merveilleux, commun (nécessite un lien)*

## Description

Cet instrument de musique possède 3 charges. Lorsque que vous en jouez, vous pouvez utiliser une action pour dépenser 1 charge et écrire un message magique sur un objet ou une surface non magique que vous pouvez voir dans un rayon de 9 mètres autour de vous.

## Capacités du message

- **Longueur du message** : Le message peut contenir jusqu'à six mots et doit être rédigé dans une langue que vous connaissez.
- **Pour les bardes** : Si vous êtes un barde, vous pouvez écrire sept mots supplémentaires et choisir de faire briller faiblement le message, lui permettant d'être vu dans des ténèbres non magiques.

## Durée et suppression

- Lancer *dissipation de la magie* sur le message l'efface.
- Sinon, le message disparaît après 24 heures.
- L'instrument récupère toutes les charges dépensées chaque jour à l'aube.
