# Casque de Vision

*Wondrous item, uncommon (requires attunement)*

## Description

Ce casque, souvent forgé par des nains ou des gnomes des profondeurs, est incrusté de lentilles de cristal sombre.

Tant que vous portez ce casque, vous bénéficiez de la **Vision dans le noir** sur une portée de 18 mètres. Si vous possédez déjà la vision dans le noir, sa portée augmente de 18 mètres.

De plus, vous avez un **Avantage** aux tests de Sagesse (Perception) basés sur la vue effectués dans une lumière faible ou dans les ténèbres.
