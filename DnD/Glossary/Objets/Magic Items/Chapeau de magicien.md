# Chapeau de magicien

*Wondrous item, common (requires attunement by à wizard)*

## Description

Ce chapeau desuet en forme de cone est orne de croissants de lune et d'etoiles dores. Tant que vous le portez, vous beneficiez des avantages suivants:

- Vous pouvez utiliser le chapeau comme focaliseur d'incantation pour vos sorts de magicien.
- Vous pouvez essayer de lancer un sort mineur que vous ne connaissez pas. Celui-ci doit figurer sur la liste des sorts de magicien et vous devez effectuer un jet d'Intelligence (Arcanes) DD 10. En cas de réussite, vous lancez le sort. En cas d'échec, le sort echoue également et l'action utilisée pour lancer le sort est perdue. Dans les deux cas, vous ne pourrez plus utiliser cette propriété avant d'avoir termine un repos long.
