# Parfum envoûtant

*Objet merveilleux, commun*

## Description

Cette petite fiole contient un parfum magique, suffisant pour une utilisation. Vous pouvez utiliser une action pour appliquer le parfum sur vous-même, et son effet dure 1 heure. Durant ce temps, vous avez un avantage à tous les jets de Charisme dirigés contre des humanoïdes de FP 1 ou inférieur.

Ceux qui subissent l'effet du parfum ne savent pas qu'ils ont été influencés par la magie.
