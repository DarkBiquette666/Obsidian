# Chapeau de deguisement

*Wondrous item, uncommon (requires attunement)*

## Description

Tant que vous êtes equipe de ce chapeau, vous pouvez à volonte, par une action, l'utiliser pour lancer le sort *deguisement*. Le sort prend fin si le couvre-chef est retire.
