# Cle mysterieuse

*Wondrous item, common*

## Description

Un point d'interrogation est grave sur la tete de cette cle. La cle à 5% de chances de deverrouiller n'importe quelle serrure dans laquelle elle est inseree. Une fois qu'elle a deverrouille quelque chose, la cle disparait.
