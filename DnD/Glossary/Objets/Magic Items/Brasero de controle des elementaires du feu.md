# Brasero de controle des élémentaires du feu

*Wondrous item, rare*

## Description

Tant qu'un feu brale dans ce brasero en cuivre, vous pouvez utiliser une action pour prononcer son mot de commande et convoquer un élémentaire du feu, comme si vous aviez lance le sort *invocation d'élémentaire*. Le brasero ne peut plus être utilise de cette facon avant la prochaine aube. Le brasero pese 2,5 kg.
