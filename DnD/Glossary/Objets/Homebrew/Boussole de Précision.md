# Boussole de Précision

**Type :** Objet Merveilleux
**Rareté :** Peu commun
**Prix :** 40 po
**Poids :** 0.5 kg

> [!info] Description
> Une boussole en laiton lourd avec un couvercle en verre loupe.

**Propriété :** Contrairement à une boussole normale, celle-ci peut être "verrouillée" sur une direction spécifique (Nord, Sud, mais aussi "La Tour Peste" si elle est visible). Une fois verrouillée, elle aide à maintenir un cap parfait même dans le brouillard ou la tempête de neige, donnant un **Avantage** aux tests de **Sagesse (Survie)** pour éviter de se perdre.
