# Chargement

*propriété d'arme*

Vous ne pouvez tirer qu'un seul projectile lorsque vous prenez une action, une action Bonus ou une Reaction pour attaquer avec une arme dotée de la propriété Chargement, quel que soit le nombre d'attaques que vous pourriez normalement effectuer.

## Armes avec cette propriété

- Arbalète légère
- Arbalète de poing
- Arbalète lourde
- Mousquet
- Pistolet
- Sarbacane
