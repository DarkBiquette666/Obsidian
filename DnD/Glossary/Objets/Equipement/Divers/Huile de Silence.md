# Huile de Silence

**Type :** Consommable (Huile)
**Rareté :** Peu Commun
**Prix moyen :** 50 po

> [!info] Description
> Une huile grise qui étouffe les sons.

**Effet :**
Appliquée sur une armure (intermédiaire ou lourde), elle supprime le **Désavantage** aux tests de **Dextérité (Discrétion)** imposé par l'armure pour une durée de **1 heure**.
