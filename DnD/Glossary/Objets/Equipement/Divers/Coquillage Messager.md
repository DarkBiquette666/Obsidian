# Coquillage Messager

**Type :** Objet Merveilleux
**Rareté :** Commun
**Prix moyen :** 25 po

> [!info] Description
> Un gros coquillage nacré.

**Effet :**
Vous pouvez murmurer un message de 25 mots maximum à l'intérieur.
Le message reste stocké jusqu'à ce que quelqu'un porte le coquillage à son oreille. Le message est alors délivré avec votre voix, puis s'efface.
