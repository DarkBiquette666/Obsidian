# Confrérie des Juges

## Description
Enquêteurs efficaces, les juges traquent les ennemis de la religion dans la civilisation. Ce sont des meneurs nés qui dirigent leur troupe d'une main de fer. Là où les répurgateurs s'éloignent souvent des enseignements de leurs dieux, les juges se voient comme leurs représentants, au même titre que les clercs. Réfléchis et tenaces, rien ne les arrête pour mener les mauvais à la justice. Ils représentent les dieux de l'ordre, la protection et la connaissance.

## Capacités

### Niveau 3 : Jugement du Commandeur
Vous apprenez le jugement du commandeur (ne compte pas dans votre limite).
*   **Effet** : Quand vous prononcez ce jugement, sélectionnez un nombre de créatures consentantes égal à votre modificateur de Sagesse (min 1).
*   **Bonus** : Quand ces créatures attaquent la cible jugée, elles gagnent un bonus aux jets d'attaque égal à la moitié de votre bonus de maîtrise (arrondi à l'inférieur).

### Niveau 3 : Investigateur
Vous pouvez lancer le sort **Zone de Vérité** une fois sans dépenser d'emplacement de sort.
*   **Récupération** : Repos long (ou entre deux repos longs).

### Niveau 3 : Sentence
Vous pouvez utiliser votre Action pour ordonner à un allié d'attaquer.
*   L'allié utilise sa Réaction pour effectuer une seule attaque.
*   Il doit pouvoir vous voir et vous entendre.

### Niveau 6 : Bénédiction du Bourreau
Quand vous utilisez votre capacité **Sentence**, les dégâts de l'attaque de l'allié ciblé sont augmentés de **1d8**.

### Niveau 11 : Condamnation
Quand vous utilisez votre capacité **Sentence**, vous pouvez utiliser votre Action Bonus pour effectuer une attaque avec une arme.

### Niveau 15 : Consécration
Vous pouvez utiliser votre Action pour brandir votre symbole sacré.
*   **Effet** : Toutes les créatures de votre choix dans un rayon de 9m doivent faire un JdS Sagesse.
*   **Échec** : 3d10 + Niveau Inquisiteur (Radiant) et Effrayé pendant 1 minute (JdS fin de tour).
*   **Réussite** : Moitié des dégâts, pas effrayé.
*   **Bonus** : Après utilisation, vous êtes sous l'effet de *Protection contre le mal et le bien* pendant 1 minute (sans concentration).
*   **Récupération** : Repos long.
