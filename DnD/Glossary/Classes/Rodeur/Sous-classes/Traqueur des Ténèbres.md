# Traqueur des Ténèbres

## Description
Les Traqueurs des Ténèbres sont à l'aise dans les endroits les plus sombres : les profondeurs de la terre, les ruelles sombres et les forêts primaires.

## Capacités

### Niveau 3 : Magie de Traqueur (Gloom Stalker Magic)
Sorts supplémentaires : *Déguisement*, *Corde enchantée*, *Peur*, *Invisibilité supérieure*, *Semblance*.

### Niveau 3 : Embusqué Redoutable (Dread Ambusher)
Vous gagnez un bonus à l'initiative égal à votre modificateur de Sagesse.
Au début de votre premier tour de combat, votre vitesse augmente de 3 mètres.
Si vous prenez l'action Attaquer ce tour-là, vous pouvez faire une attaque d'arme supplémentaire qui inflige 1d8 dégâts supplémentaires (Dégâts psychiques en 2024 ?).
**Mise à jour 2024** : *Dreadful Strike* pour dégâts psychiques constants ou burst initial amélioré.

### Niveau 3 : Vue des Ombres (Umbral Sight)
Vision dans le noir (18m). Si vous l'avez déjà, portée +9m.
Vous êtes invisible pour toute créature qui utilise la vision dans le noir pour vous voir dans l'obscurité.

### Niveau 7 : Esprit de Fer (Iron Mind)
Vous gagnez la maîtrise des jets de sauvegarde de Sagesse. Si vous l'avez déjà, choisissez Intelligence ou Charisme.

### Niveau 11 : Rafale du Traqueur (Stalker's Flurry)
Une fois par tour, si vous manquez une attaque d'arme, vous pouvez faire une autre attaque d'arme dans le cadre de la même action.
(Ou mise à jour 2024 : *Dreadful Strike* amélioré, permet de faire peur).

### Niveau 15 : Esquive ténébreuse (Shadowy Dodge)
Lorsque vous êtes attaqué par une créature sans avantage, vous pouvez utiliser votre réaction pour imposer un désavantage à l'attaque.
