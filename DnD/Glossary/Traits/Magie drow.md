# Magie drow

Vous connaissez le sort mineur lumières dansantes. Lorsque vous atteignez le niveau 3, vous pouvez lancer le sort lueurs féeriques une fois par jour. Lorsque vous atteignez le niveau 5, vous pouvez lancer le sort ténèbres une fois par jour. Le Charisme est votre caractéristique d'incantation pour ces sorts.
