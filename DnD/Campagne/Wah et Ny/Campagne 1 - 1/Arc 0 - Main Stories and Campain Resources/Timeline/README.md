# Systeme de Timeline Narrative - Guide Rapide

## Structure Creee

```
Timeline/
├── Events/           Evenements individuels
├── Decisions/        Points de choix critiques
├── Outcomes/         Consequences des decisions
├── World-States/     Etats du monde
├── Canvas/           Visualisations graphiques
└── Etat-Actuel-Campagne.md  Note centrale de tracking
```

## Templates Disponibles

Dans Templates/:
- Timeline-Event.md
- Timeline-Decision.md
- Timeline-Outcome.md
- Timeline-World-State.md

## Canvas Crees

1. **Timeline-Master.canvas** - Vue macro de toute la campagne
   - Passe (Pacte + 4 phases corruption)
   - Present (Arcs 1-5)
   - Futurs possibles (4 fins)

2. **Timeline-Arc1-Detail.canvas** - Vue micro Arc 1
   - Tous les embranchements possibles
   - Sidequests
   - Decisions critiques
   - Outcomes multiples

## Workflow

### Avant Session
1. Consulter Etat-Actuel-Campagne.md
2. Identifier evenements possibles
3. Preparer decisions potentielles

### Pendant Session
- Noter decisions PJ
- Tracker interactions
- Marquer flags actives

### Apres Session
1. Mettre a jour Etat-Actuel-Campagne.md
2. Creer notes Outcome pour decisions prises
3. Planifier prochaine session

## Note Centrale

**Etat-Actuel-Campagne.md** contient:
- Flags actifs
- Variables numeriques
- Statut factions
- Statut PNJ
- Evenements possibles
- Notes session
- To-do prochaine session

Mettez a jour apres CHAQUE session!

## Prochaines Etapes

1. Consulter Timeline-Master.canvas pour vue d ensemble
2. Ouvrir Timeline-Arc1-Detail.canvas pour preparer Arc 1
3. Utiliser templates pour creer vos propres evenements
4. Personnaliser Etat-Actuel-Campagne.md selon votre situation
