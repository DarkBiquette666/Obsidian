# La Disparition d'Alfonse

## Description
Simon découvre que l'Hermite Alfonse a été enlevé.
Il trouve :
- Un morceau de **Tissu Rouge** (Cape des ravisseurs).
- Des notes sur un **Contre-Elixir**.
- Il purifie le puits et sauve Bart.

## Indices Clés
- Les ravisseurs portent du rouge (L'Assemblée).
- Ils ciblent les savants (Alfonse est chimiste).
