# Système de Timeline à Embranchements - README

## Bienvenue!

Vous disposez maintenant d un système complet pour gérer une histoire narrative complexe avec de multiples embranchements, comme dans Baldur's Gate.

## Ce Qui a Été Créé

### Structure Complète

```
Timeline/
├── Events/          # Événements individuels
├── Decisions/       # Points de choix critiques
├── Outcomes/        # Résultats possibles
├── World-States/    # États du monde
├── Canvas/          # Visualisations
└── Guide/           # Documentation
```

## Démarrage Rapide

### 1. Familiarisation (10 min)

- Ouvrez **[[Etat-Actuel-Campagne]]**
- Explorez **Timeline-Master.canvas**
- Regardez **Timeline-Arc1.canvas**

### 2. Préparer Session 1 (30 min)

- Lisez E01-Arrivee-Village-Trepied
- Lisez D01-Enquete-Village
- Créez 5-6 PNJ du village
- Préparez carte du village

### 3. Jouez!

- Amenez joueurs au village
- Laissez-les explorer
- Réagissez à leurs choix

### 4. Après Session (15 min)

- **METTRE À JOUR [[Etat-Actuel-Campagne]]** (CRUCIAL!)
- Cocher événements accomplis
- Modifier flags et variables
- Noter préparation prochaine session

## Principe Fondamental

**Le système sert l histoire, pas l inverse**

Si joueurs font quelque chose d inattendu → Improviser et documenter après!
