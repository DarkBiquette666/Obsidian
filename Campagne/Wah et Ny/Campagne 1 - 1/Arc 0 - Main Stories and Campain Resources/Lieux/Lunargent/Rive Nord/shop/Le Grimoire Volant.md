# Le Grimoire Volant

**Type :** Librairie Arcanique
**Lieu :** Lunargent - Rive Nord
**Propriétaire :** [[Archimage Gallad]]

> [!info] Ambiance
> Le silence est absolu dès qu'on franchit la porte, imposé par un sort permanent. Les livres s'envolent d'eux-mêmes pour se ranger. L'odeur de vieux papier et d'ozone est enivrante pour tout magicien.

## Description
Vane vend du savoir pur. C'est l'endroit rêvé pour les Magiciens, Sorciers et Bardes.
